# Professional Portfolio

This is a premium, modern, and professional personal portfolio website template designed for showcasing projects, education, and professional experience. It implements a clean, semantic HTML5 structure with vanilla CSS and progressive JavaScript.

## Project Structure

The project layout is structured for professional development and future growth:

```text
├── index.html       # Main HTML file implementing a semantic structure
├── css/             # Sheets directory
│   └── styles.css   # Main CSS styling file containing layout and theming
├── js/              # Client-side JavaScript directory
│   └── main.js      # Interactive features and animations
├── images/          # Images and graphic assets (e.g. avatars, project captures)
├── assets/          # General assets (e.g. downloadable Resume/CV PDFs)
└── README.md        # Project documentation
```

## Semantic Layout Architecture

The homepage is structured semantically to ensure accessibility, search engine friendliness (SEO), and maintainability:

1. **HEADER**: Branding, identity, and navigation toggles.
2. **NAVIGATION**: A responsive navigation bar with smooth scroll anchors.
3. **MAIN**:
   - **ABOUT**: Introduction, role title, skills, and background.
   - **EDUCATION**: History of courses and certifications.
   - **PROJECTS**: Gallery of featured work with details, tech badges, and demo links.
   - **CONTACT**: Contact form and social links.
4. **FOOTER**: Secondary links, back-to-top button, and copyright notice.

## Features

- **Dark Tech Theme**: Sleek background gradients, grid details, and cyber neon glows.
- **Glassmorphism Design**: Frosted glass navigation bars and cards with blur effects.
- **Responsive Layout**: Designed to work beautifully on mobile, tablet, and wide desktop screens.
- **Micro-Animations**: Hover animations on links and project cards for an engaging UX.
- **Smooth Interactivity**: Scroll spy navigation, intersection reveals, and a mobile drawer.

## Usage

1. Open `index.html` directly in a browser or run a local development server.
2. Customize the text content inside the semantic tags in `index.html`.
3. Add project thumbnails to the `images/` directory.
4. Replace or add files in `assets/` (e.g. your downloadable CV).
